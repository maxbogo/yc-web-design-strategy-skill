# Web Design Strategy — Agent Skill

A strategic web design consultant skill built from [Y Combinator's Design Review series](https://youtube.com/playlist?list=PLQ-uHSnFig5PjnaLTBMsCcE7YPye6-xTX&si=EJY34ob0PhpOPwe6) — where YC partners critique real startup websites and landing pages.

This skill distills those reviews into an actionable framework: stage-aware design, the five-second filter, AI slop detection, conversion optimization, and a comprehensive QA checklist.

## When to Use

This skill activates when you:

- **Build** a website or landing page for a product or startup
- **Review or critique** an existing site's design, messaging, or conversion flow
- **Write** hero copy, value propositions, or CTAs
- **Plan** information architecture for a marketing site

### Examples

- *"Build me a landing page for my developer tool"*
- *"Review this site and tell me what's wrong with the messaging"*
- *"Write hero copy for a B2B SaaS product targeting DevOps teams"*
- *"Audit this page — does it look like AI slop?"*
- *"What should go above the fold for a pre-launch waitlist page?"*

## Installation

```bash
npx skills add maxbogo/yc-web-design-strategy-skill
```
